# Umayyad Strike — ضربة الأمويين

لعبة تكتيكية 5 ضد 5 على نمط Counter-Strike (زرع/تفكيك العبوة) تدور في **ساحة الأمويين في دمشق**، مبنية على **Unreal Engine 5.5** بلغة C++ مع أنظمة الرسوميات الحديثة: Lumen (إضاءة عامة وانعكاسات بتتبع الأشعة) و Nanite و Virtual Shadow Maps و TSR.

## التشغيل لأول مرة

1. ثبّت **Unreal Engine 5.5** (أو أحدث) و **Visual Studio 2022** مع حزمة "Game development with C++".
2. انسخ المجلد إلى `D:\New folder (5)` (أو أي مسار)، ثم انقر بالزر الأيمن على `UmayyadStrike.uproject` ← **Generate Visual Studio project files**.
3. افتح `UmayyadStrike.uproject` ووافق على بناء الوحدة (Build). يُفضّل بطاقة تدعم DX12 / SM6 وتتبع الأشعة (RTX 2070 فما فوق).
4. داخل المحرر: **Tools ← Execute Python Script** واختر `Content/Python/build_umayyad_square.py`.
   السكربت يبني الخريطة كاملة `/Game/Maps/UmayyadSquare` ويحفظها (يمكن إعادة تشغيله في أي وقت، فهو يحذف ما بناه سابقاً فقط).
5. اضغط **Play** (Alt+P). لتجربة اللعب الجماعي: Play ← Number of Players = 2..10، Net Mode = Play As Listen Server.

> لا تحتاج اللعبة أي أصول (assets) جاهزة كي تعمل: المدخلات (Enhanced Input) والواجهة (HUD + قائمة الشراء) مبنية بالكود، والخريطة تُبنى بالسكربت.

## تصميم المرحلة — ساحة الأمويين

```
                     شمال  ↑  (جبل قاسيون في الأفق مع أضواء البيوت)
                 مبنى الإذاعة والتلفزيون  ← موقع B
        شارع العدوي ↖              ↗ المالكي / أبو رمانة
  الفندق والحدائق                          
 [مدافعون] ← طريق المزة/بيروت    ● نُصب السيف الدمشقي (الوسط)    شارع شكري القوتلي → [مهاجمون]
                                           
   دار الأوبرا ← موقع A          ↓ طريق المعرض/بردى      مجمع هيئة الأركان (حدود الخريطة)
```

- **الوسط (Mid):** الجزيرة الدائرية ونُصب السيف الدمشقي: عمود بمداميك "أبلق" (بازلت أسود ورخام أبيض — توقيع العمارة الدمشقية)، نافورة بثلاث طبقات و16 نافورة ماء، ممشى رخامي وجدران منخفضة للتغطية، وإضاءة ذهبية من الأسفل.
- **الموقع A — دار الأوبرا:** رواق أعمدة وأقواس، درج رخامي عريض (نقطة زرع مرتفعة)، واجهة زجاجية بتوهج داخلي دافئ، أحواض سرو وصناديق للتغطية.
- **الموقع B — الإذاعة والتلفزيون:** برج بنوافذ مضاءة، سارية بث بأضواء حمراء، مظلة مدخل، سيارة بث خارجي، مولّد وحواجز خرسانية.
- **الحركة المرورية المتجمدة:** حافلات حمراء، سيارات أجرة صفراء، سيارات — هي لغة التغطية الأساسية حول الدوّار.
- **الأكشاك** (عصير/كعك)، مواقف الحافلات، نخيل وسرو، أعمدة إنارة مزدوجة، حواجز عند مداخل الشوارع (نقاط اختناق).
- **الأجواء:** ساعة ذهبية — شمس منخفضة من الغرب، سماء فيزيائية، غيوم حجمية، ضباب غباري حجمي، Auto-Exposure و Local Exposure، تدرج ألوان سينمائي (ظلال مائلة للأزرق وإضاءات دافئة)، Bloom و Lens Flare وحبيبات فيلم خفيفة.

> المخطط تفسير لعِب (gameplay) للساحة الحقيقية. للمطابقة الدقيقة: عدّل الإحداثيات في السكربت مقابل صور الأقمار الصناعية (≈ 33.5130 شمالاً، 36.2765 شرقاً) وصور مرجعية للمباني.

## أنظمة اللعب (C++)

| الملف | الوظيفة |
|---|---|
| `USCharacter` | حركة بأسلوب CS (تسارع وكبح حاد، مشي صامت، إبطاء عند الإصابة)، صحة ودرع وخوذة، أصوات خطوات حسب السطح، Ragdoll عند الموت، مدخلات مبنية بالكود |
| `USWeapon` | إطلاق Hitscan مُتنبَّأ محلياً ومُتحقَّق منه على الخادم، نمط ارتداد قابل للتعلّم (شكل "7")، دقة الطلقة الأولى، انتشار حسب الحركة/القفز/الانحناء، اختراق الدرع، سقوط الضرر مع المسافة، مضاعف الرأس ×4، مؤثرات إصابة حسب نوع السطح |
| `USGameMode` | نظام MR12 (أول من يصل 13، تبديل الجهات بعد 12)، وقت شراء، مكافآت قتل وفوز، سلّم تعويض الخسارة، زرع وتفكيك، شروط الإقصاء، موازنة الفرق |
| `USBomb` | صفير يتسارع من 1 ث إلى 0.1 ث، ضوء وامض، انفجار بسقوط ضرر غاوسي |
| `USHUD` + `SUSOverlay` | تقاطع ديناميكي، علامات إصابة (رأس/قتل)، وميض ضرر، منظار، شريط النتيجة والوقت، سجل القتل، شريط التفكيك، **نصوص عربية مُشكَّلة بشكل صحيح عبر Slate**، قائمة شراء |

الأسلحة: Glock-18، USP-S، Desert Eagle، AK-47، M4A4، AWP + درع، درع وخوذة، عدة تفكيك.

## الوصول لجودة ألعاب 2026 — خطة الأصول

الكود والإعدادات جاهزة لأعلى جودة؛ ما يرفع الصورة من "نموذج أولي" إلى مستوى AAA هو استبدال الأشكال الأولية بأصول حقيقية. كل عنصر في السكربت موضوع في مجلد باسمه داخل الـ Outliner (`Umayyad/OperaHouse`، `Umayyad/Monument` …) لتسهيل الاستبدال:

1. **المواد:** من **Fab / Quixel Megascans** (مجانية مع Unreal): حجر كلسي، بازلت، رخام، أسفلت مبلل، أرصفة. استبدل `MI_*` في `/Game/Umayyad/Materials` — كل المباني تتحدث تلقائياً.
2. **المباني:** نمذجة الأوبرا والنُصب ومبنى التلفزيون (Blender أو Modeling Mode داخل المحرر) مع تفعيل **Nanite** على كل الشبكات.
3. **الشخصيات:** **MetaHuman** لشخصيات الفريقين + أنيميشن Motion Matching (مشروع Game Animation Sample من Epic).
4. **المؤثرات (Niagara):** `NS_MuzzleFlash`، `NS_Tracer` (بمُعامل `BeamEnd`)، شظايا حجر/رخام/معدن/زجاج، رذاذ ماء النافورة، غبار في أشعة الشمس، `NS_Explosion` بدخان حجمي — تُسند في خصائص `USWeapon` و `USBomb`.
5. **الصوت (MetaSounds):** طبقات لكل طلقة (قريب + صدى بعيد يرتد عن الواجهات عبر `FireTailSound`)، Convolution Reverb بطابع الساحة المفتوحة، أصوات مدينة (حركة سير بعيدة، أذان بعيد عند المغرب، نافورة، طيور)، مُعلِّق بصوت دمشقي (`AnnouncerLines`)، وموسيقى قصيرة على مقام الحجاز بالعود والإيقاع (`MusicStingers`).
6. **الأسطح الفيزيائية:** أنشئ Physical Materials (Stone, Metal, Water, Glass, Marble …) — القنوات معرّفة مسبقاً في `DefaultEngine.ini` — لتعمل أصوات الخطوات ومؤثرات الإصابة حسب السطح.
